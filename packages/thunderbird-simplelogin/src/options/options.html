SimpleLogin Aliases

Account

Create a key in SimpleLogin under Settings → API Keys. It can list and create aliases on your account, so treat it as a credential — it is stored in Thunderbird's extension storage inside your profile, unencrypted.

The key is being supplied by a managed-storage manifest outside Thunderbird, so this field is read-only. Change it at the source instead.
